# C fidelity audit, 2026-09-06

Twenty functions sampled across 20 subsystems, each compared against the Ghidra
disassembly (not the decompiler view) by four independent reviewers. Scores are
0-5: fidelity 5 = provably identical behavior; C quality 5 = idiomatic, typed,
endian-safe, arch-isolated, accurately commented.

Method notes: reviewers traced every instruction of each function, checked callee
prologues for argument shapes, read PC-relative constant cells with `gsk read`,
compiled headers with `m68k-elf-gcc` to check struct offsets, and in two cases
compiled the C to confirm what `-O2` emits.

## Systemic failure modes

These recur across reviewers and subsystems; they are the checklist for any
re-emission pass.

1. **Pascal by-reference constants passed as NULL or immediates.** `pea (d,PC)`
   to a word/byte in the code region is a `var`/`const` parameter. Seen in
   OS_$INIT (nine sites), area, xns, ring, name, xpd, os. The correct idiom
   (file-static constant, address taken) already exists in os/init.c and
   pmap/purifier_l.c.
2. **Booleans typed `uint8_t`.** Domain booleans are 0xFF tested with
   `tst.b`/`bmi`; `>= 0` on an unsigned byte is always true. Made whole paths
   unreachable in FILE_$PRIV_LOCK, PROC2_$FORK, SMD, TTY.
3. **Byte operations on the high byte of a word.** `bset.b #n,(off,An)` on the
   first byte of a 16-bit field means bit n+8 of the word. PROC2_$FORK is wrong
   at every flag write; ML_$UNLOCK tests bit 10 of an 8-bit field.
4. **Struct layouts that do not match the binary.** `smd_globals_t` (+0x200),
   `ring_unit_t`/`ring_global_t`, rem_file frame, `startup_context_t`,
   `vtoc_alloc_req_t`, boot-param record in OS_$INIT. Only `route_$port_t` has a
   `_Static_assert`, and it is the one that is right.
5. **A6 displacements used as struct offsets** for records passed by `pea (-N,A6)`
   (xns demux, both parameter records).
6. **Unimplemented regions hidden behind prose** ("omitted for brevity",
   "... complex cleanup ...", empty `if` bodies with a comment claiming the work
   is done). Found in priv_lock, rem_file server, os init, route process, stop
   watch, vtoc allocate, ast dispatch. Several files have zero `TODO:` markers.
7. **Nested-procedure flattening that copies an uplevel variable by value**
   when the callee mutates it (cal write_calendar control byte, dir insert
   page_link), or that turns a zero-parameter nested procedure into a global
   with an invented ABI (ast set_attr_dispatch).
8. **By-value arrays and records.** `EC_$WAIT` takes two 3-element arrays by
   value (24 bytes); ec.h's prototype decays to pointers and no caller in the
   kernel can be faithful. `RIP_$FIND_NEXTHOP` gets the original instead of a
   12-byte copy.
9. **Forced-IPL-0 exits rendered as SR restore**, and `move SR,-(SP)` restores
   rendered as nothing (ml, crash_system, stop).
10. **Hardware access that the optimizer deletes**: non-volatile delay loops
    (cal, time), non-volatile MMIO (ring), write-then-reread of status registers.
11. **Wrong half of `status_$t`**: `tst.w (2,An)` is the low word; `bset.b #7,(An)`
    is bit 31. Several files invert one or the other.
12. **Off-by-one on 1-based Pascal arrays** (`SOCK_$EVENT_COUNTERS[sock]`,
    segmap base, proc1_$type lookup, dir loop bounds).
13. **Tests that exercise nothing**: several test files re-implement the logic
    locally instead of `#include`-ing the .c (ml, route, time partly). None of the
    20 audited functions has a test that calls the real function with the
    interesting inputs.
14. **Ghidra out of sync**: ~15 helpers referenced by name in C are still `FUN_`
    in the database (area_$alloc_resources, four xns helpers, four stop helpers,
    six FILE_$PRIV_LOCK_FUN_*, cal delay entries); most of OS_$INIT's callees are
    unnamed; `ACL_TYPE_FILE` at 0xE5472E is a mislabel (it is a TIME_$WAIT
    delay-type zero word).

## Verified one-line fixes (assembly address in parentheses)

These are the cheapest high-value corrections; each was independently justified
by the reviewer with the cited instruction.

- name/lock_dir.c:155 `*handle_ret = MST_$MAPS(...)` result, and :156 test the
  low half of status (0xE54AD8, 0xE54AE2).
- tty/i_rcv.c:60 mask `0x20` not `0x2000` (0xE1B95E).
- ast/set_attr_dispatch.c:318 `needs_purify` not `needs_truncate` (0xE0514C).
- route/process.c:127 `SOCK_$EVENT_COUNTERS[ROUTE_$SOCK - 1]` (0xE87428).
- ml/unlock.c:77 and ml/exclusion_stop.c:77 mask `0x04` (0xE20ED0); add the
  missing `DISABLE_INTERRUPTS` in exclusion_stop's no-waiter path (0xE20EAC).
- ring/rcv.c:218 swap the busy/not-busy arms (0xE76170).
- proc2/fork.c:102,104,108,111,166,181,183,447 multiply flag constants by 0x100.
- cal/write_calendar.c: thread the control byte by reference with
  `*control -= 0x10` (0xE8173E); mark delay loops volatile here and in
  time/read_cal.c.
- pmap/purifier_l.c:240 real loop; :120 `below_thresh >= 0 && carryover == 0`;
  SEGMAP base 0xED4F80.

## Implications for process

- A function is not done until every basic block of the original is accounted
  for; prose ellipses are not acceptable, `TODO:` plus a bead is.
- Every struct whose layout was recovered from the assembly should carry
  `_Static_assert`s on the documented offsets and `sizeof` under `ARCH_M68K`.
- Booleans should use the `boolean` type from base.h and be tested with `< 0`.
- Any `pea (d,PC)` needs a named file-static constant.
- Tests must `#include` the .c under test and call the real function.
- The reviewer checklist in the project memory
  (domain-pascal-codegen-conventions) captures the conventions behind items 1-12.

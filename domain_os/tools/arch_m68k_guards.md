# Architecture guards outside arch/ (source-702z)

Generated by: Claude Opus 5.5

The last step of docs/design-per-process-data.md (source-0i3) forbids
`#if` / `#ifdef` / `#ifndef` / `#elif` on `ARCH_M68K` or `ARCH_HOST` (any
spelling) around data.  `make check` runs `tools/check_guards.py`
(`check-guards`), which scans every `*.h` and `*.c` outside `arch/`,
`build/`, `dist/` and `tools/` and fails on a guard holding an object
declaration or definition (including one made through a macro such as
`MODULE_DATA_DEFINE`), any `extern`, a `#define` that casts an absolute
address to a pointer (a literal, or a macro that expands to one:
`(T *)(uintptr_t)DIR_A5_BASE_VA`, `(T *)(CAL_$RTC_BASE + off)`), or a struct
or union definition.  This table is the human-checked version of
`check_guards.py --report` on the converted tree.

Classes (the ones the step's bead defines):

| class | meaning | allowed | guards |
|---|---|---|---|
| a | `_Static_assert`s on a pointer-bearing record, true only on the 32-bit target | yes | 152 |
| b | host fallback body of a routine that is hand-written assembly on the target (`<subsystem>/sau2/*.s`) | yes | 35 |
| c | `.text.<symbol>` section-attribute macro for the target's link order | yes | 5 |
| d | hardware register access | only in `arch/` or a per-SAU header | 0 (see below) |
| e | data declaration / definition or absolute-address macro | no: converted, or exempt for a tracked bead | 16 exempt |

## What source-702z converted

Module data, now one object on every build (a MODULE_DATA block unless
noted): `APP_$DATA` (app/app.h, was three absolute macros), `HINT_$DATA`
(plus `HINT_$HINTFILE_PTR` and `HINT_$EXCLUSION_LOCK` as plain map-named
objects), `NETBUF_$DATA`, `PEB_$INFO` (the PEB_PARITY segment, with
`PEB_$INSTALLED_FLAG` / `M68881_$SAVE_FLAG` as its fields; `M68881_EXISTS` a
plain object), `WIN_$DATA` (with the image's driver entry table),
`XPD_$DATA` (source-c6cy), `VOLX_$DATA`, `MMAP_$DATA` (the MMAP_ segment),
`DXM_$SIGNAL_ROUTINES` (the DXM_WIRED_ segment); `ML_$LOCK_BYTES` /
`ML_$LOCK_EVENTS` (map LOCK_BYTE / LOCK_$EVENT_LISTS, self-linked
eventcounts), `ast_$attr_timestamp_mask` and `ast_$not_found` (plain objects
until source-gmxj), the FILE_$LOT_DATA tables (objects that already existed:
the target now uses them), `DISK_$PER_PROC` (through `DISK_$DATA`).  Unused
spellings were deleted (MAC_OS table / lock / port / socket macros,
`PTE_BASE`, `IO_$INT_STACK`, `PEB_GLOBALS_BASE`, `PEB_WIRED_DATA_ADDR`,
`PEB_PRIVATE_BASE`), and host-only definitions left the kernel's
`_data.c` files (fp/fp_data.c and prom/prom_data.c are gone; the DXM
callback registry is test support in dxm/test/dxm_host_callbacks.h).
`name/handle_map.c` is gone: `NAME_$HANDLE_TO_PTR` is `ARCH_VA_TO_PTR`.

Hardware (class d), now in arch: `SAU2_DMAC_BASE` (ring channels 0..2 and
the floppy's channel 3), `SAU2_MEM_ERR_STATUS_LONG/_WORD`, `SAU2_PAR_BUFF`,
`SAU2_PEB_CTL` / `_DCMD_PAGE` / `_CS_PAGE`, `SAU2_CALENDAR_BASE`,
`SAU2_TIMER_BASE` (arch/m68k/sau2/hw.h); `ARCH_IO_READ8` / `ARCH_IO_WRITE8`
(the RTC and timer byte accesses; host hooks `arch_$io_read8/_write8`),
`ARCH_PROM_MACHINE_ID` (the PROM cell at 0x100) and `ARCH_VECTOR` (the
vector table OS_$INIT writes) in arch/<arch>/arch.h.  A host test that runs
code touching a SAU2 register defines the `SAU2_` name itself.
